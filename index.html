Things I've built

LostAndFound: Smart Item Recovery Platform

🏆 2nd place · Final Year Project

A platform that helps people report lost items, post found items, and return them safely to their real owners. Android app and website share one Firebase backend, so everything stays in sync in real time.

  • ML Kit OCR and image labeling describe items automatically from photos
  • Hugging Face semantic similarity checks ownership claims for fraud before handover
  • Real-time chat, map view, multi-photo upload and in-app notifications
  • Admin panel to manage users, posts and claims, with analytics
